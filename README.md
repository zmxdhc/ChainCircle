# ChainCircle

ChainCircle harnesses high-performance, auto-scaling architecture for ultra-fast, scalable real-time data processing within a robust system platform.

ChainCircle is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainCircle.git`
2. `cd ChainCircle`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
